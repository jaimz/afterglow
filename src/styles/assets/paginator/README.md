# Paginator artwork

`selected.svg` is the unmodified 28 × 28 SVG export of the selected-page oval
from the [Mobile Paginator](https://www.figma.com/design/EAs4mNS5YP0qRcKfN4HGST/Mobile?node-id=149-1).
It contains the 20px selection circle and its shadow, and is rendered at its
native size behind the current page label.
