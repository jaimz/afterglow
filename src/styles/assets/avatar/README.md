# Avatar assets

`blank.svg` is the unchanged logo export used by the [Avatar component, node 204:112](https://www.figma.com/design/EAs4mNS5YP0qRcKfN4HGST/Mobile?node-id=204-112). The native recipe uses it as a mask so it follows the theme colour.

`Comfortaa.ttf` is the unmodified variable font from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/comfortaa), used at weight 300 to match the Figma initials. It is redistributed with its original [SIL Open Font License](OFL.txt). The stylesheet loads it from the accompanying assets directory, without contacting a font service at runtime.
