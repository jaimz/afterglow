# Feather icons

These 287 original SVGs were supplied from the downloaded Feather icon set. They retain their original filenames, 24 × 24 view boxes and two-unit rounded strokes. The files are used unchanged as CSS masks, so Afterglow can colour them with the surrounding text colour.

Feather is by Cole Bemis and contributors. The upstream [MIT licence](https://github.com/feathericons/feather/blob/main/LICENSE) is included as [LICENSE](LICENSE) and is copied with the assets when building Afterglow.

Add or remove SVGs here, then run `bun run build:icons` to regenerate the pure Sass catalogue in `src/styles/_feather.scss`. Storybook's icon gallery reads the available filenames automatically. Run `bun run test:styles` to check that the catalogue and assets agree.
