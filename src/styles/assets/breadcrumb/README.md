# Breadcrumb assets

Original, unmodified SVG exports from the [AFMaster Breadcrumb sketch, node 87:13](https://www.figma.com/design/7Hz5rGL1JRLfouCckw8FIq/AFMaster?node-id=87-13).

- `star.svg`: the 16 × 16px favourite icon in each Breadcrumb Label.
- `chevron-right.svg`: the 18 × 18px separator between labels.

The breadcrumb uses these as CSS masks to inherit the current foreground colour. Its `star` icon overrides the shared Feather star only inside breadcrumb links; other optional icon names continue to use the shared Feather catalogue. SVG dimensions and vector data remain unchanged.
